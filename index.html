ファイル 1 つを保存すれば、手元で動きます

どのアプリも HTML ファイル 1 つでできています。

各アプリの「開く」でそのままブラウザで使えます。「ダウンロード」でそのファイルを保存すれば、ダブルクリックするだけで、ネットにつながっていないパソコンでも動きます。

推奨ブラウザは Chrome・Edge

パソコンの Chrome か Edge で使ってください。ほかのブラウザでもアプリは動きますが、保存と印刷で違いが出ます。

多くのアプリでは、開いたファイルにそのまま上書き保存できます。この機能は、ブラウザの File System Access API を使っています。この API はパソコンの Chrome や Edge にはありますが、Safari や Firefox、スマートフォンのブラウザにはありません。ほかのブラウザでは、上書き保存の代わりに、保存のたびにファイルをダウンロードします。

また、Safari などでは、印刷機能を使った PDF への書き出しでレイアウトが崩れることがあります。SVG で保存できるアプリでは、SVG 形式での保存をおすすめします。

テキスト記法で書く

★ の付いたアプリは、Markdown やプログラムのようなテキスト記法で書いた内容から、スライドや図などを作ります。テキスト記法はアプリごとに独自に決めてあります。

テキストで書くので、生成 AI に書かせることも、GitHub などで複数人の変更を管理することもできます。

生成 AI と一緒に使う

アプリごとに、生成 AI 向けのプロンプトを用意しています。お使いの ChatGPT や Claude などに頼むときは、最初にそのプロンプトを渡してください。AI がそのアプリのテキスト記法で書くので、そのまま貼って使えます。なお、アプリ自身には生成 AI は入っていません。

  1. アプリの「プロンプトをコピー」を押し、生成 AI に貼る
  2. 続けて、作りたいものの内容を伝える
  3. AI が書いたものを、アプリに貼る
  4. できたものを見て、直したい点を AI に伝える

プロンプトとともに、アプリの HTML ファイルそのものも AI に渡す方法もあります。AI がアプリの中身を読めるので、細かい調整を頼みやすくなります。

※アプリから生成 AI に何かが送られることはありません。AI に渡すのは、あなたが貼ったプロンプトや HTML ファイルと、頼んだ内容だけです。

複数人で作る

複数人で作るときは、書いたテキストを Git と GitHub などで管理する共同作業をおすすめします。Git なら、誰が、いつ、どこを、なぜ変えたかが記録に残り、取り込む前に変更を確かめることもできます。

なお、同じ画面を何人かで同時に編集する機能はありません。

回路図 ★

シンプルな独自のテキスト記法で書く回路図。

学生が正しい記号で回路図を描けるようになるために作りました。記号は、日本の高校の教科書などで使われる「日本式」、JIS C 0617・IEC 60617 の図記号どおりの「JIS/IEC」、IEEE 315 を基本に米国でよく使われる「米国式」から選べます。

U1.D13 -- R1 -- D1 -- GND のように、つなぐ順に書くだけで線が引かれます。電気回路・電子回路から、Arduino とセンサーの回路まで描け、LED の逆向きなどの誤りも警告します。SVG・PNG・PDF で保存でき、スライドや TeX の報告書に貼れます。

開く ダウンロード 使い方 ソース

プロジェクト計画 ★

テキストで書く、プロジェクト計画。

機能から製品、作業、担当、日程までを、一続きに計画できるようになるために作りました。絵を描くことよりも、計画の漏れや矛盾を見つけることと、日程を計算することに重点を置いています。

- 画面の実装 days: 3 after: 画面設計 のようにタスクを書くだけで、FBS・PBS・WBS・アローダイアグラム・ガントチャート・テスト項目(MOP)の表・サマリーなど、10 の図と表が描かれます。クリティカルパスを求め、担当者のタスクの重なりと休みを避けて日程を組みます。図と表は SVG・PNG・PDF で保存でき、スライドや報告書に貼れます。

単体で使え、マイログやプロジェクト分析と組み合わせても使えます。

開く ダウンロード 使い方 ソース

生成 AI に計画のテキストを書かせるときは、最初にこのプロンプトを AI に渡してください。警告が出たら、アプリの「修正依頼をコピー」で AI に直してもらえます。

マイログ ★

テキストで書き足す、日々の作業の記録。

プロジェクトの実行中に起きている問題を、早く見つけるために作りました。作業時間を数えることより、詰まっていないか、依頼が放置されていないかを拾い出すことに重点を置いています。

1 人 1 ファイルで、- 通知用APIの実装 hours: 3 progress: 40 のように、日付ごとに作業・問題・依頼・テストの結果を書き足します。表は SVG・PNG・PDF で保存できます。

単体で使え、プロジェクト計画の計画書を読み込むと、名前の照合、担当のタスク、計画を使う問題の兆候、今週の予定も確認できます。

開く ダウンロード 使い方 ソース

生成 AI に質問してもらいながら今日の記録を作るときは、アプリの「AI で記録」からプロンプトをコピーしてください。人の名前は伏せて渡します。

プロジェクト分析

計画と記録から、プロジェクトを振り返る。

振り返りを、次のプロジェクトの運営に生かすために作りました。完了報告書に載せる表や図の原案を作れます。

プロジェクト計画の計画書だけでも、マイログだけでも、両方でも読み込めます。計画書を読み込むと、版ごとの比較、改訂履歴、終了日やバーンアップなどの推移を示します。表と図は SVG・PNG・PDF で保存できます。

マイログを読み込むと、作業時間、依頼と返事の突き合わせ、問題の兆候などを示します。複数人のマイログをまとめて読み込めます。両方を読み込むと、計画に書き写す候補も示します。計画書もマイログも読むだけで、書き換えはしません。

データを送らない仕組み

アプリはすべて、お使いのブラウザの中で動いています。入力した文章や描いた図がサーバーに送られることはありません。作業中の内容はお使いのブラウザの中に、保存したファイルはお使いのパソコンに残ります。
